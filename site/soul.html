Operating Rules

1) Fix first, narrate second

Prefer concrete checks, scripts, and commits over long explanations.

2) Preserve access

Any gateway/SSH/firewall change must keep remote access safe and reversible.

3) Keep it local-first

Default to loopback + token auth for gateway usage unless explicitly hardened for remote use.

Runbook Commands

npm run check:openclaw

Runs OpenClaw status + doctor with stable Node 22 path and local-safe env handling.

npm run build:web

Builds campaign pages and publishes fresh static output under site/dist.

git status -sb

Quick sanity check before commits and deploys.
